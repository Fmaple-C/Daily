# 枫叶计划项目功能文档

## 文档维护规则

后续每次新增、修改或删除功能时，都需要同步更新本文档。

- `当前版本功能清单`：记录软件实际已经支持的功能。
- `状态定义`：记录计划状态和打卡状态的判断规则。
- `功能变更记录`：记录改动日期、版本、内容和影响范围。
- `待规划功能`：记录暂未实现但后续考虑的能力。

## 项目定位

枫叶计划是一款本地离线、数据保存在手机本机的计划管理软件。它的核心不是团队项目管理，而是个人计划与打卡记录。

当前核心场景：

- 日计划：记录每天、当日或某个日期范围内要完成的计划。
- 月计划：记录每月、当月或某个日期范围内的规划。
- 年计划：记录每年、当年或某个日期范围内的长期目标。
- 一言：随时新增一句话、灵感、想法或生活片段，不需要打卡。
- 随记：保存较完整的记录、复盘或草稿，并支持轻量 Markdown 展示。
- 备注：计划可以保存较长备注，用来写账本、学习计划、月度规划等内容。
- 打卡历史：每一次打卡都会保存具体打卡时间和打卡备注。
- 日夜主题：用户可以在白天主题和夜间主题之间切换。
- 离线使用：不需要账号，不依赖网络。

## 目标用户

- 想记录每日习惯、每日记账、日常复盘的人。
- 想做月度学习、理财、思维训练、行业观察等规划的人。
- 不想登录账号、不想依赖云端，只希望本机可用的人。

## 当前版本功能清单

### 1. 模块与计划类型导航

界面顶部先区分功能模块：

- 计划。
- 一言。
- 随记。

进入计划模块后，再提供紧凑计划类型选择：

- 日计划。
- 月计划。
- 年计划。

切换后，列表会按对应模块或计划类型展示。新建表单默认收起，点击右上角“新建”或“记录”按钮后展开，避免新建区域占用主列表空间。

### 2. 新建日计划

日计划支持三种周期：

- 每日：每天都生效。
- 当日：只在创建当天生效。
- 日期范围：在指定开始日期到结束日期之间生效。

日计划支持：

- 计划名称。
- 备注。
- 每日截止打卡时间，默认 `12:00`。
- 打卡。
- 超时提示。

示例：

```text
计划：每日记账
备注：
1. 上班交通地铁-12元
2. 早餐-4元
3. 午餐-13元
4. 晚餐-15元
5. 日支出=12+4+13+15=44元
```

### 3. 新建月计划

月计划支持三种周期：

- 每月：每个月都生效。
- 当月：只在当前月份生效。
- 日期范围：在指定开始日期到结束日期之间生效。

月计划支持：

- 计划名称。
- 备注。
- 打卡。
- 按月份判断本月是否已经打卡。

示例：

```text
计划：每月规划
备注：
1. internal本
   1. 运用 ai 学习 java
   2. 玩 blog
   3. 部署线上环境，锻炼服务器管理能力，ci/cd
      1. jenkins
      2. Vm - ubuntu
      3. 阿里云
   4. 业务扩展
2. 理财本
   1. 学习基金
   2. 看《一本书读懂财报》
3. 思维本
   1. 学习批判性思维
   2. 金字塔原理
4. 行业本
   1. 兼职
```

### 4. 新建年计划

年计划支持三种周期：

- 每年：每一年都生效。
- 当年：只在当前年份生效。
- 日期范围：在指定开始日期到结束日期之间生效。

年计划支持：

- 计划名称。
- 备注。
- 打卡。
- 按年份判断今年是否已经打卡。

示例：

```text
计划：年度成长计划
备注：
1. 技术主线
   1. Java 深入
   2. 做一个完整产品
2. 健康主线
   1. 稳定锻炼
   2. 年度体检
3. 资产主线
   1. 学习理财
   2. 建立预算系统
```

### 5. 计划编辑

用户新增 TODO 后，可以继续编辑计划信息。

当前支持编辑：

- 计划名称。
- 计划备注。
- 周期模式。
- 日期范围。
- 日计划截止打卡时间。

编辑入口位于计划卡片操作区的“编辑”按钮。进入编辑后，顶部表单会带入当前计划内容，保存后保留原有打卡历史。

### 6. 一言记录

一言用于随时随地新增记录，不需要打卡。

当前规则：

- 顶部导航提供“一言”入口。
- 右上角按钮显示“记录”，点击后展开记录表单。
- 记录内容不能为空。
- 每条记录保存创建时间。
- 列表按最新到最旧展示。
- 一言卡片以“言”标识、时间和正文展示。
- 支持删除单条一言记录。

适合记录：

- 一句话想法。
- 临时灵感。
- 当下心情。
- 碎片复盘。

### 7. 随记

随记用于保存更完整的个人记录，适合写复盘、草稿、学习笔记和较长想法。

当前规则：

- 顶部导航提供“随记”入口。
- 右上角“新建”按钮展开随记表单。
- 随记支持标题和正文。
- 正文按原始 Markdown 文本保存。
- 列表中提供轻量 Markdown 展示，当前支持标题、列表、引用、代码和基础强调符号清理。
- 随记按最新到最旧展示。
- 支持编辑和删除单篇随记。

示例：

```md
# 今日复盘

- 完成 Android 模块拆分
- 梳理后续存储迁移

> 明天继续优化历史列表
```

### 8. 备注能力

计划可以填写多行备注。

当前规则：

- 备注可以为空。
- 备注按原文本保存。
- 适合写清单、账本、规划、复盘内容。

### 9. 打卡历史与备注

每次点击打卡都会新增一条打卡记录。

当前规则：

- 日计划打卡记录到具体日期，例如 `2026-05-14`。
- 月计划打卡记录到具体月份，例如 `2026-05`。
- 年计划打卡记录到具体年份，例如 `2026`。
- 每条打卡记录保存具体时间，例如 `2026-05-14 15:30`。
- 每条打卡记录可以保存一段备注。
- 同一计划同一天、同一个月或同一年可以打卡多次，列表展示最近 3 条。
- 计划卡片右侧提供下箭头，点击后在卡片内快速展开全部打卡时间和备注。
- 计划卡片提供“历史”按钮，点击后进入完整打卡历史页，专门查看该计划的全部打卡记录。

### 10. 日夜主题

用户可以在界面右上角切换日间和夜间主题。

当前规则：

- 日间主题使用枫叶橙和浅暖色背景。
- 夜间主题使用深暖色背景和高亮枫叶橙。
- 主题选择会保存在本地，下次打开应用继续生效。

### 11. 应用图标

应用图标使用“枫叶 + 对勾”的矢量 logo。

当前规则：

- 图标跟随 Android 原生资源构建。
- 不依赖外部图片文件。
- 适配普通图标和 Android 8.0 以上 adaptive icon。

### 12. 本地离线保存

软件使用本地存储保存计划数据。

当前规则：

- 不需要登录。
- 不需要网络。
- 数据保存在应用私有目录。
- 卸载应用或清除应用数据会删除本地数据。
- 当前数据版本为 `schemaVersion = 5`。
- 旧版 TODO 数据会自动迁移为日计划。

### 13. 枫叶橙主题

界面使用枫叶橙作为主色，配合浅暖色背景。

当前视觉方向：

- 主色：枫叶橙。
- 背景：浅暖色。
- 完成状态：绿色。
- 超时状态：红橙色。

## 核心用户流程

### 创建日计划

1. 点击顶部“日计划”。
2. 点击右上角“新建”。
3. 输入计划名称，例如“每日记账”。
4. 填写备注。
5. 选择“每日”“当日”或“日期范围”。
6. 如选择日期范围，设置开始日期和结束日期。
7. 设置截止时间。
8. 点击“添加日计划”。

### 创建月计划

1. 点击顶部“月计划”。
2. 点击右上角“新建”。
3. 输入计划名称，例如“每月规划”。
4. 填写备注。
5. 选择“每月”“当月”或“日期范围”。
6. 如选择日期范围，设置开始日期和结束日期。
7. 点击“添加月计划”。

### 创建年计划

1. 点击顶部“年计划”。
2. 点击右上角“新建”。
3. 输入计划名称，例如“年度成长计划”。
4. 填写备注。
5. 选择“每年”“当年”或“日期范围”。
6. 如选择日期范围，设置开始日期和结束日期。
7. 点击“添加年计划”。

### 编辑计划

1. 在计划卡片中点击“编辑”。
2. 顶部表单展开并带入当前计划内容。
3. 修改计划名称、备注、周期、日期范围或截止时间。
4. 点击“保存修改”。
5. 原有打卡历史继续保留。

### 记录一言

1. 点击顶部“一言”。
2. 点击右上角“记录”。
3. 写下一句话、灵感或想法。
4. 点击“保存一言”。
5. 一言列表按最新到最旧展示。

### 写随记

1. 点击顶部“随记”。
2. 点击右上角“新建”。
3. 输入标题。
4. 在正文中输入 Markdown 内容。
5. 点击“保存随记”。
6. 随记列表展示轻量 Markdown 预览。

### 编辑随记

1. 在随记卡片中点击“编辑”。
2. 修改标题或正文。
3. 点击“保存修改”。

### 打卡

1. 在计划卡片中点击“打卡”。
2. 填写本次打卡备注，可以留空。
3. 软件保存当前打卡时间和备注。
4. 卡片状态变为今日、本月或今年已打卡。
5. 再次点击可以“再记一次”，用于保存多次打卡时间。

### 查看打卡备注

1. 在计划卡片右侧点击下箭头。
2. 卡片展开后展示全部打卡时间和备注。
3. 再次点击箭头可以收起。

### 查看完整打卡历史页

1. 在计划卡片中点击“历史”。
2. 进入该计划的完整打卡历史页。
3. 页面按最新到最旧展示所有打卡记录。
4. 每条记录展示所属周期、打卡时间和打卡备注。
5. 点击顶部“返回”回到计划列表。

## 状态定义

| 状态 | 条件 | 展示 |
| --- | --- | --- |
| 待打卡 | 当前日期在计划周期内，且当前周期未打卡 | 显示“待打卡” |
| 今日已打卡 | 日计划在今天至少有一条打卡记录 | 显示“今日已打卡” |
| 本月已打卡 | 月计划在本月至少有一条打卡记录 | 显示“本月已打卡” |
| 今年已打卡 | 年计划在今年至少有一条打卡记录 | 显示“今年已打卡” |
| 已超时 | 日计划今日未打卡，且当前时间超过截止时间 | 显示“已超时” |
| 未开始 | 当前日期早于计划开始日期 | 显示“未开始” |
| 已结束 | 当前日期晚于计划结束日期 | 显示“已结束” |

## 非目标功能

当前版本暂不做以下能力：

- 账号登录。
- 云同步。
- 多设备同步。
- 团队协作。
- 复杂看板。
- 社交分享。

## 待规划功能

- 打卡历史统计，例如连续打卡天数、月完成率。
- 通知提醒，例如截止前 30 分钟提醒。
- 排序与置顶。
- 数据导出与导入。
- 本地备份。
- 更完整的大屏布局适配。
